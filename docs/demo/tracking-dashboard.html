物理叙事（Ground Truth）

弹丸（Ø20mm 半球形弹头，V₀=600 m/s）撞击 Weldox 460E 靶板（12mm 厚）， 经历 0 → 0.0360 ms 内首轮接触应力（峰值 431.85 MPa）， 在 frame 36 达到材料的 JC 侵蚀准则，首删 4 个 plate 壳单元。 弹丸继续穿透，frame 93 (t=0.0932 ms) 时 von Mises 应力达到 731.49 MPa——— 这不是事后峰值，是实时求解的数值。后续 frame 121/125 各再删 2 个单元， 末态共 8/120 plate 单元侵蚀，但背面（back face）仍存活，状态为 embedded_candidate， 不是"完成穿透"。弹丸最大位移 133.45 mm。
