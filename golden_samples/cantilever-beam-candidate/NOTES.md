## Geometry

A slender steel cantilever fixed at one end, transverse point load at
the free tip.

| parameter | value | unit |
|---|---|---|
| length L | 1.0 | m |
| cross-section depth h | 0.1 | m |
| cross-section width b | 0.1 | m |
| aspect ratio L/h | 10.0 | — |
| second moment I = b·h³ / 12 | 8.3333…e-6 | m⁴ |
| tip load P | -1000.0 | N (downward) |
| Young's modulus (steel-s355) | 210e9 | Pa |

## Expected analytical (Euler-Bernoulli)

δ_tip = P · L³ / (3 · E · I)
     = -1000 · 1.0³ / (3 · 210e9 · 8.3333e-6)
     = -1.9048e-4 m  (−0.19 mm)

Sign convention: negative δ_tip ↔ downward, matching the load
direction.

## Phase 21 A residual envelope (honest C3D4 bending convergence)

Phase 21 A's `run_cantilever_cross_check` lands a -6.88% residual at
characteristic mesh length 0.015 m (≈7 elements through-thickness).
The C3D4 (linear tet) mesh is shear-locking-prone on bending; even at
this refinement, the observed deflection sits ~7% below the
Euler-Bernoulli analytical. The tolerance is set to 15% which is
comfortably wider than the observed residual; tightening below 10%
needs C3D10 (quadratic tets) which is Phase 22+ scope (the gmsh +
adapter both need C3D10 support).
