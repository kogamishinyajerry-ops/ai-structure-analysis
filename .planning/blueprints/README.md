# Project Blueprints — versioned vision archive

> **Tier 1 engineering candidate; not signed validation; not benchmark agreement.**

Each subdirectory under this folder is one **frozen** snapshot of the
project's visual vision (the 8-image set) generated at a phase-close
boundary. They are vision artifacts, not engineering deliverables — see
each version's `README.md` for when-to-reference rules.

## Versions

| Version | Generated at | Cover |
|---------|--------------|-------|
| [`v1_phase11_close/`](v1_phase11_close/) | 2026-05-16 (post Phase 11 close, FINAL TAA 100/100) | First canonical 8-blueprint set: system arch / reviewer workbench / data flow / advisor-not-driver / trust chain / analysis matrix / cohort dashboard / day in the life |

## Bump policy

A new version lands when:
- The project's North Star changes (e.g., a major scope pivot).
- A phase closes and the visual gap between the latest image set and the
  new reality is material enough to warrant a regeneration.
- A reviewer specifically asks for a vision refresh.

**Old versions are never deleted.** They preserve the historical
trajectory; deletion would erase the audit trail of project direction
changes.
